# Decathlon Retail Analytics

## Project Overview

This project analyzes synthetic Decathlon retail transaction data to understand sales performance, profitability, customer behavior, product performance, store performance, sales channels, promotions, returns, and delivery experience.

The analysis covers transactions from January 2024 through December 2026.
